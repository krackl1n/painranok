# РАНОК 2D Lab

Небольшая локальная веб-лаборатория по методическим указаниям «Локальная компьютерная геометрия» (МГТУ «СТАНКИН», 2019).

## Запуск

Требуется Node.js 22.18+ (для встроенного запуска TypeScript-тестов).

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Для production: `npm run build`, затем `npm start`.

## Возможности

- Вставка кода, импорт UTF-8 `.dat`/`.txt`, сохранение `.dat`, автосохранение в localStorage.
- RECTANGLE, RECTBMP, ARGUMENT, CONSTANT, FUNCTION, RETURN.
- Арифметика, степень `^`, пересечение `&`, объединение `|`, дополнение унарным минусом; `diff(A,B)` = `A&(-B)`, `intersect`, `union`, `neg`. Обычное `A-B` вычитает значения функций.
- Функции abs, sqrt, sin, cos, tan, exp, ln/log (натуральный логарифм), min, max, pow; pi и e.
- Десять примеров, поле значений, область, приближённый нулевой контур, сетка и оси.
- Выбор произвольной точки мышью или ввод координат; значения всех переменных.
- PNG в разрешении RECTBMP (с выбранной сеткой и траекториями, без маркера выбранной точки), CSV всех узлов с колонками x,y,W.
- Парсер без eval/Function; расчёт сетки в Web Worker. Ошибки с номером строки.

## Численная модель и совместимость

Имена переменных чувствительны к регистру (`f` и `F` различаются), команды — нет. Определения должны предшествовать использованию. Два аргумента соответствуют X и Y в порядке объявления. Одна команда на строку; комментарии `//`, `#`, необязательная завершающая `;`. Десятичный разделитель в коде — точка.

Приоритет: степень (справа налево), унарные +/−, умножение/деление, сложение/вычитание, &, |. Для явного порядка используйте скобки.

Выбрано стандартное семейство R₀: `a & b = a+b-hypot(a,b)`, `a | b = a+b+hypot(a,b)`. [Математика R-функций](https://userpages.umbc.edu/~rostamia/cbook/rvachev-functions.pdf). Методичка не задаёт параметр семейства; численные значения и оттенки могут отличаться от настольного РАНОК. Совместимость с бинарной программой не проверялась.

Сетка включает границы RECTANGLE; строка 0 соответствует Ymax. Максимум 1000×1000 узлов, 200 определений, 512 токенов на выражение, 50 000 символов кода. Нулевой контур определяется сменой знака между соседними узлами и точными нулями. Это растровое приближение, не аналитический поиск всех корней: мелкие детали и касания могут быть пропущены. Разрывы также могут давать смену знака. Значения NaN/Infinity показаны розовым и экспортируются пустым W в CSV.

## Инструменты заданий

1. R-моделирование: десять примеров, включая животное, разность областей и сложную сцену. Код свободно редактируется.
2. Контур по точкам: ввод 3–40 вершин, автоматическая ориентация и триангуляция невыпуклого контура. Внутренние диагонали перекрываются дополнительными областями, чтобы R-объединение не создавало ложных нулевых швов. Самопересечения и касания отклоняются. Генерируется редактируемый код.
3. Траектории: спуск, подъём, движение по касательной в обе стороны; начальная точка на холсте или числом; шаг 0.1–10 пикселей, до 10000 итераций; несколько цветных путей, очистка, PNG и CSV. Пример RFM из пособия и сцена с кругом, квадратом и треугольником.
4. Конструктор потенциалов: координаты и сила цели, таблица препятствий (до 30), готовая сцена с десятью препятствиями. Генерация кода, затем запуск траектории. Также доступен конструктор RFM с круглыми препятствиями; другие фигуры задаются уравнениями.
5. Производство: таблица неотрицательных ограничений a·x+b·y≤c и целевая линейная функция, x,y≥0. Перебор допустимых пересечений прямых даёт решение непрерывной ограниченной задачи; генерируется штрафная функция из методички. Отдельно — численный минимум/максимум произвольного RETURN по сетке с локальным уточнением.

Спуск и подъём используют центральные разности и поиск улучшения среди направлений с уменьшением шага. Проверяются промежуточные точки шага для снижения риска перескока через барьер. Это численная эвристика, не гарантия обхода любого препятствия. Для касательной используется шаг по ортогональному градиенту с проекцией на исходный уровень. Сообщается причина остановки; локальный минимум не считается достигнутой целью. Поиск экстремума по сетке не гарантирует глобальный оптимум между узлами. Градиенты в изломах — численные оценки.

## Образы и экспорт

Переключатель образа не меняет RETURN и функцию, по которой идёт траектория. Кроме W доступны численные Wx, Wy, нормаль (Nx,Ny,Nz)=(-Wx,-Wy,1)/sqrt(1+Wx²+Wy²) и D для касательной плоскости Nx·x+Ny·y+Nz·z+D=0. Производные считаются по сетке, по краям — односторонней разностью.

Кнопка «7 BMP · ZIP» сохраняет volume.bmp (W), dzxp.bmp (Wx), dzyp.bmp (Wy), AuAll.bmp (Nx), BuAll.bmp (Ny), CuAll.bmp (Nz), DuAll.bmp (D). Каждый образ независимо нормируется в оттенки серого, кроме цветного volume. BMP без сетки и траекторий. Это численные аналоги с именами из методички, не побайтовая реализация внутренних образов настольной программы; её точные формулы кодирования пособие не раскрывает.


## Проверка

```sh
npm test
npm run lint
npm run build
```

Тесты проверяют язык, разность областей, примеры, производные, монотонность спуска/подъёма, сохранение уровня касательной, обход препятствий RFM, уточнение экстремума, невыпуклые контуры без внутренних швов, решение производства (0,30; 720), форматы BMP и ZIP.
